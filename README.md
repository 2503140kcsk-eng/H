# Starlight Wing — 星の翼

iPhoneの横画面・タッチ操作を想定した、オリジナル3D宇宙シューティングゲームです。Vite + TypeScript + Three.jsを使った静的PWAとして開発しています。

## 開発中の状態

**MVP / 縦切り版を開発中です。** すべての完成条件を満たした完成版ではありません。

現時点で追加した基盤:
- Three.jsによるトップダウン3Dシーン、3層の星背景、オリジナルの簡易機体・敵・ボス形状
- タッチドラッグ移動、自動射撃、3種の敵、敵弾、ピックアップ、シールド、特殊攻撃
- フェーズを持つボス戦、HP / シールド / スコア / 撃破数 / コンボ
- Dexieを使った端末内セーブ、Zodによる値の検証、チェックサム付きJSONバックアップ
- iPhone向けPWAマニフェストとオフラインキャッシュ設定
- Vitestによる戦闘計算・セーブ検証のテストとGitHub Actions

まだ実装・実機確認していない主な機能:
- 10種類すべての敵、複数パイロット・機体・スキン、完全な武器ツリー
- 長編ストーリー、豊富な会話・ボイス、複数惑星のキャンペーン
- 作曲済みBGM、状況連動サウンド、完成版の演出とアニメーション
- 機種変更を含むiPhone実機でのバックアップ往復テスト
- iPhone Safari / Braveでの長時間・熱・フレームレート測定

## ローカル開発

Node.js 22以上を推奨します。

```bash
npm install
npm run dev
```

本番ビルドとテスト:

```bash
npm test
npm run build
npm run preview
```

## iPhoneでの試遊

**公開ブランチのブラウザ試遊:** [StackBlitzで feature/starlight-wing-mvp を開く](https://stackblitz.com/github/2503140kcsk-eng/H/tree/feature/starlight-wing-mvp)

StackBlitzはこの公開GitHubブランチを読み込むため、ブランチへの新しいコミットが試遊環境へ反映されます。読み込み後にViteのプレビューを起動し、プレビューを別タブで開くとiPhoneで操作しやすくなります。iOS SafariでのWebContainersはベータ対応で、メモリ制限により大きなプロジェクトで停止する場合があります。まずSafariで試し、プレビューが起動しない場合はPCブラウザでの確認が必要です。iOS版BraveでのStackBlitz開発環境の動作は未検証です。

このStackBlitz URLは**開発用プレビュー**であり、正式な配布URLやiPhone実機の動作保証ではありません。ゲームのセーブ領域もStackBlitzのプレビューオリジンに属します。実機でのPWAインストール、Safari / BraveのGPU負荷、長時間プレイ、機種変更復元は別途確認が必要です。

iOSブラウザが画面向きの強制固定を受け付けない場合があるため、縦向きでは回転案内を表示します。

## セーブとバックアップ

- 進行状況はDexie / IndexedDBを使って端末内に保存します。
- ハンガーからJSONバックアップを書き出せます。
- 読み込み時はファイル形式・チェックサムを先に検証し、復元処理はIndexedDBトランザクションで行います。
- 復元前のセーブは端末内の復元スナップショットに保管します。

チェックサムは破損検出用で、暗号学的な署名や改ざん防止ではありません。バックアップのコピーはiCloud Driveなど利用者が管理する場所に保存してください。

## パフォーマンス方針

- アンチエイリアスと高負荷ポストエフェクトを初期設定で切り、devicePixelRatioを1.25に制限
- 敵・弾・粒子の同時数を制限
- フレーム時間に基づく移動・当たり判定
- タブが非表示になった場合は一時停止
- 60 FPSは目標であり、iPhone実機で確認するまでは達成を主張しません

## ライセンスと素材

初期版はコードで生成した簡易3D形状とWeb Audioの短い合成音を中心にしています。外部モデル・音楽・画像を追加する際は、個別ファイルのライセンス、帰属表示、再配布条件を確認します。
