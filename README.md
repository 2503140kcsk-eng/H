# Starlight Wing — 星の翼

iPhoneの横画面・タッチ操作を想定した、オリジナル3D宇宙シューティングゲームです。Vite + TypeScript + Three.jsを使った静的PWAとして開発しています。

## 開発中の状態

**MVP / 縦切り版を開発中です。** すべての完成条件を満たした完成版ではありません。

現時点で追加した基盤:
- Three.jsによるトップダウン3Dシーン、3層の星背景、オリジナルの簡易機体・敵・ボス形状
- タッチドラッグ移動、自動射撃、9種の敵（狙撃・爆撃・追尾ミサイル・防御・群体・エリートを含む）、敵弾、ピックアップ、シールド、特殊攻撃
- フェーズを持つボス戦、HP / シールド / スコア / 撃破数 / コンボ
- 7種の戦闘ピックアップ：シャード、修理、オーバードライブ、マルチショット、シールド回復、速度強化、特殊ゲージ回復
- 3種類のオリジナル兵装：標準単発スター・パルス、3方向拡散プリズム・ファン、高威力で追加1体を貫くノヴァ・ランス。シャードで恒久解放・装備し、セーブとJSONバックアップへ保存
- 3機体の選択・シャードによる恒久解放。高速型／重装型は移動・連射・攻撃・耐久・シールド回復が異なり、3D形状も変化
- 3人のオリジナルパイロットを選択・恒久解放。攻撃・連射・移動・最大HP・シールド回復・必殺技に個性があり、コックピット色にも反映。経験値とLvはパイロット別に保存し、Lvで攻撃力・HPが成長
- ユーザー所有のVRMをパイロットごとに読み込み、ハンガーに全身3Dプレビューを表示。モデルは端末内IndexedDBだけに保存し、最大32 MiB、通信送信なし。ビューアーコードは初回PWAプリキャッシュから除外し、初回利用後に専用キャッシュ。JSON進行バックアップとは別保存なので機種変更時はVRMファイルを再読込
- Dexieを使った端末内セーブ、Zodによる値の検証、チェックサム付きJSONバックアップ（機体・パイロット・兵装の解放と選択を保存。旧version 1バックアップは新フィールドを既定値で補完）
- iPhone向けPWAマニフェストとオフラインキャッシュ設定
- Vitestによる戦闘計算・セーブ検証のテストとGitHub Actions
- iPhone・ブラウザ診断：直近600フレーム、描画統計、WebGL上限、IndexedDBと保存領域を端末内で収集しJSON / CSVへ出力

まだ実装・実機確認していない主な機能:
- パイロット専用ストーリー・ボイス・個別スキルツリー、追加機体・スキン、完全な武器ツリー（3機体・3パイロットの選択・解放・個別Lv/XP成長、通常敵9種＋ボス1種の戦闘ロールは基盤実装済み）
- 長編ストーリー、豊富な会話・ボイス、複数惑星のキャンペーン
- 作曲済みBGM、状況連動サウンド、完成版の演出とアニメーション
- 機種変更を含むiPhone実機でのバックアップ往復テスト
- iPhone Safari / Braveでの長時間・熱・フレームレート測定

## ローカル開発

Node.js 22以上を推奨します。

```bash
npm install
npm run dev
```

本番ビルドとテスト:

```bash
npm test
npm run build
GITHUB_PAGES=true GITHUB_REPOSITORY=2503140kcsk-eng/H npm run build
npm run verify:pages
npm run preview
```

## 無料のGitHub Pages配布

公開リポジトリ向けのGitHub Pages用Actionsワークフローを追加しています。Vite・PWAのパスはリポジトリ型サイト（`/H/`）としてビルド・検査し、`main` ブランチへの反映後だけデプロイします。想定URLは `https://2503140kcsk-eng.github.io/H/` ですが、これはPagesを有効化して初回デプロイが成功するまで未公開です。

初回だけGitHubの **Settings → Pages → Build and deployment → Source → GitHub Actions** を選択してください。PRやfeatureブランチからは公開されず、`main` へのマージ後にデプロイが実行されます。GitHub Pagesは公開リポジトリでGitHub Freeから利用できますが、リポジトリ設定をこの作業環境から変更できないため、設定選択はリポジトリ管理者側で必要です。

## iPhoneでの試遊

**公開ブランチのブラウザ試遊:** [StackBlitzで feature/starlight-wing-mvp を開く](https://stackblitz.com/github/2503140kcsk-eng/H/tree/feature/starlight-wing-mvp)

StackBlitzはこの公開GitHubブランチを読み込むため、ブランチへの新しいコミットが試遊環境へ反映されます。読み込み後にViteのプレビューを起動し、プレビューを別タブで開くとiPhoneで操作しやすくなります。iOS SafariでのWebContainersはベータ対応で、メモリ制限により大きなプロジェクトで停止する場合があります。まずSafariで試し、プレビューが起動しない場合はPCブラウザでの確認が必要です。iOS版BraveでのStackBlitz開発環境の動作は未検証です。

このStackBlitz URLは**開発用プレビュー**であり、正式な配布URLやiPhone実機の動作保証ではありません。ゲームのセーブ領域もStackBlitzのプレビューオリジンに属します。実機でのPWAインストール、Safari / BraveのGPU負荷、長時間プレイ、機種変更復元は別途確認が必要です。

iOSブラウザが画面向きの強制固定を受け付けない場合があるため、縦向きでは回転案内を表示します。

## セーブとバックアップ

- 進行状況はDexie / IndexedDBを使って端末内に保存します。
- ハンガーからJSONバックアップを書き出せます。
- 読み込み時はファイル形式・チェックサムを先に検証し、復元処理はIndexedDBトランザクションで行います。
- パイロット選択・個別成長を追加した後もセーブ形式version 1を維持し、旧version 1バックアップや旧端末レコードの共通経験値は読み込み時点の選択パイロットへ移行します。
- 復元前のセーブは端末内の復元スナップショットに保管します。

チェックサムは破損検出用で、暗号学的な署名や改ざん防止ではありません。バックアップのコピーはiCloud Driveなど利用者が管理する場所に保存してください。

## iPhone・ブラウザ診断

ハンガーの「設定 → iPhone・ブラウザ診断」から端末レポートを取得し、JSON / CSVへ書き出せます。ゲームを一度プレイしてから診断すると、平均・95パーセンタイル・最悪フレーム間隔、推定FPS、Three.jsの描画呼出数・三角形数、WebGL上限、描画バッファ寸法、IndexedDB / Storage APIの状態を含みます。

診断処理自体は外部送信しません。ファイルを共有する場合はUser-Agent等の端末・ブラウザ情報を確認してください。温度・バッテリー・GPU使用率・実メモリ量はブラウザAPIから直接取得できません。Playwrightの成功はiPhone実機合格を意味しません。実機手順は [iPhone Quality Gate](docs/qa/iphone-quality-gate.md) を参照してください。

## パフォーマンス方針

- アンチエイリアスと高負荷ポストエフェクトを初期設定で切り、devicePixelRatioを1.25に制限
- 敵・弾・粒子の同時数を制限
- フレーム時間に基づく移動・当たり判定
- タブが非表示になった場合は一時停止
- 60 FPSは目標であり、iPhone実機で確認するまでは達成を主張しません

## ライセンスと素材

初期版はコードで生成した簡易3D形状とWeb Audioの短い合成音を中心にしています。外部モデル・音楽・画像を追加する際は、個別ファイルのライセンス、帰属表示、再配布条件を確認します。
