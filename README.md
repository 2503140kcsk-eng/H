# Starlight Wing — 星の翼

iPhoneの横画面・タッチ操作を想定した、オリジナル3D宇宙シューティングゲームです。Vite + TypeScript + Three.jsを使った静的PWAとして開発しています。

## 開発中の状態

**MVP / 縦切り版を開発中です。** すべての完成条件を満たした完成版ではありません。

現時点で追加した基盤:
- Three.jsによるトップダウン3Dシーン、3層の星背景、オリジナルの簡易機体・敵・ボス形状
- タッチドラッグ移動、自動射撃、9種の敵（狙撃・爆撃・追尾ミサイル・防御・群体・エリートを含む）、敵弾、ピックアップ、シールド、特殊攻撃
- フェーズを持つボス戦、HP / シールド / スコア / 撃破数 / コンボ
- 7種の戦闘ピックアップ：シャード、修理、オーバードライブ、マルチショット、シールド回復、速度強化、特殊ゲージ回復
- 3機体の選択・シャードによる恒久解放。高速型／重装型は移動・連射・攻撃・耐久・シールド回復が異なり、3D形状も変化
- 3人のオリジナルパイロットを選択・恒久解放。攻撃・連射・移動・最大HP・シールド回復に加え、ノアのバリア強化、リンのオーバードライブなど固有スキルを実装。個別ストーリー/会話、パイロット別の翼・アイコンアニメーションとコックピット発光を追加。経験値とLvはパイロット別に保存
- 4種の武器と2スロット：標準弾、プリズムレーザー、追尾ホーミング弾、最大2体を貫くノヴァピアサー。シャードで解放し、戦闘中にスロットを切り替え
- 3惑星の連続キャンペーン：オーロラ・プライム、パイラ・リーチ、ノクティス・アーカイブ。惑星ごとの会話・ミッション・環境色・専用ボスに加え、戦闘中に発生する固有イベント（攻撃増幅/敵弾加速/防壁展開）と達成報酬を実装し、クリア順で次の惑星を解放
- パイロット無線通信パネル：出撃時の個別台詞、惑星イベントの通信、ボス戦の弱点開放・撃破メッセージをキュー表示
- 3種のボス：弱点コアの開閉周期、攻撃予告、扇状弾/追尾弾/十字砲火の違い、弱点命中倍率と惑星固有報酬を実装。エンドレスではボスが巡回
- オリジナルのWeb AudioシンセBGM：通常航行とボス戦でパターンを切り替え、出撃・警告・弱点開放・勝利・敗北を状況連動キューで演出。爆発粒子とカメラシェイクを追加（録音済み音源ファイルではなくコード生成）
- 6種の実績、ボス図鑑、端末内ローカルランキング。報酬・装備・惑星進行・コレクションをセーブとJSONバックアップへ保存
- Dexieを使った端末内セーブ、Zodによる値の検証、チェックサム付きJSONバックアップ（機体・パイロットの解放と選択を保存。旧version 1バックアップも既定パイロットへ移行）
- iPhone向けPWAマニフェストとオフラインキャッシュ設定
- Vitestによる戦闘計算・セーブ検証のテストとGitHub Actions

まだ実装・実機確認していない主な機能:
- 3D全身パイロットモデル（VRM等）、リップシンク/ボイス、長編の分岐ストーリー、スキルツリー
- 惑星イベントの追加分岐と複数段階化、ボスのさらなる種類/形態、武器・機体・スキンの追加とゲームバランス調整
- 録音済み/アレンジ済みの高品質BGM・効果音。現在のBGMはWeb Audioでリアルタイム合成するオリジナル短旋律
- iPhone実機同士でのファイルアプリ経由のバックアップ往復、PWAインストール、Safari/Braveでのタッチ・GPU・熱・長時間FPSの実測

## ローカル開発

Node.js 22以上を推奨します。

```bash
npm install
npm run dev
```

本番ビルドとテスト:

```bash
npm test
npm run build
npm run preview
```

## iPhoneでの試遊

**拡張ブランチの試遊用プレビュー:** [StackBlitzで feat/planetary-combat-expansion を開く](https://stackblitz.com/github/2503140kcsk-eng/H/tree/feat/planetary-combat-expansion)

StackBlitzはこの公開GitHubブランチを読み込み、Viteプレビューを起動できます。ただしWebContainersのSafari対応はベータ扱いで、iPhoneではメモリ制約やクロスオリジン分離の差により起動できない場合があります。確実なiPhone配布URLはまだ設定していません。ChatGPTの会話本文内でこのThree.js/Viteアプリ自体を直接実行することもできません。読み込み後にViteのプレビューを起動し、プレビューを別タブで開くとiPhoneで操作しやすくなります。iOS SafariでのWebContainersはベータ対応で、メモリ制限により大きなプロジェクトで停止する場合があります。まずSafariで試し、プレビューが起動しない場合はPCブラウザでの確認が必要です。iOS版BraveでのStackBlitz開発環境の動作は未検証です。

このStackBlitz URLは**開発用プレビュー**であり、正式な配布URLやiPhone実機の動作保証ではありません。ゲームのセーブ領域もStackBlitzのプレビューオリジンに属します。実機でのPWAインストール、Safari / BraveのGPU負荷、長時間プレイ、機種変更復元は別途確認が必要です。

iOSブラウザが画面向きの強制固定を受け付けない場合があるため、縦向きでは回転案内を表示します。

## セーブとバックアップ

- 進行状況はDexie / IndexedDBを使って端末内に保存します。
- ハンガーからJSONバックアップを書き出せます。
- 読み込み時はファイル形式・チェックサムを先に検証し、復元処理はIndexedDBトランザクションで行います。
- セーブ形式version 1を維持したまま、武器2枠・惑星進行・実績・ボス図鑑・ランキングを追加。旧version 1バックアップには安全な既定値を補完し、既存の機体/パイロット/経験値を保持します。
- 追加したPlaywright移行テストは、バックアップを書き出し、別ブラウザーコンテキストへ読み込む往復を検証します。実iPhone同士のAirDrop/iCloud移行を証明するものではありません。
- 復元前のセーブは端末内の復元スナップショットに保管します。

チェックサムは破損検出用で、暗号学的な署名や改ざん防止ではありません。バックアップのコピーはiCloud Driveなど利用者が管理する場所に保存してください。

## パフォーマンス方針

- アンチエイリアスと高負荷ポストエフェクトを初期設定で切り、devicePixelRatioを1.25に制限
- 敵・弾・粒子の同時数を制限
- フレーム時間に基づく移動・当たり判定
- タブが非表示になった場合は一時停止
- 60 FPSは目標であり、iPhone実機で確認するまでは達成を主張しません

## ライセンスと素材

3D機体・敵・ボスと星空はコード生成の軽量形状です。BGMは独自の旋律をWeb Audioで合成します。外部モデル・音楽・画像を追加する際は、個別ファイルのライセンス、帰属表示、再配布条件を確認します。
